## 🚀 Live Deployment via GitHub Pages
To spin up the public ecosystem dashboard directly on the web:
1. Go to your repository **Settings** tab on GitHub.
2. Select **Pages** from the left-hand navigation panel.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Set the source branch to `main` and keep the path directory to `/ (root)`.
5. Click **Save**. GitHub Actions will build and launch your visual portal automatically.
